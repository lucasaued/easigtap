# eaSIGTAP

O eaSIGTAP é um projeto de aplicação web para facilitar a consulta à tabela SIGTAP do SUS por profissionais de saúde do Hospital Universitário de Santa Maria (HUSM/UFSM).

O projeto pretende reunir a busca por procedimentos e diagnósticos, a consulta de suas relações e a visualização das órteses, próteses e materiais especiais (OPM) compatíveis. A primeira fase organiza os dados que servirão de base para essas funcionalidades, com foco inicial em Traumatologia e Ortopedia.
